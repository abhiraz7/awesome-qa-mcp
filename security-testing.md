# Security / Penetration Testing MCP Servers

> Dual-use warning: every tool below can attack real systems. Only point these at systems
> you are explicitly authorized to test (your own staging environment, or a system covered
> by a signed pentest engagement). Do not use them against third-party systems without
> written authorization.

- **CHAI pentest tool** — Autonomous penetration-testing MCP server with an integrated AI
  decision engine and a plugin architecture, so it can chain recon → exploit attempts
  → reporting steps on its own rather than requiring a human to drive each step.

- **Apviso MCP** — Connects an AI client to the APVISO AI-powered penetration-testing
  platform, exposing its scan/assessment workflow as MCP tools.
