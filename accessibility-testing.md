# Accessibility Testing MCP Servers

- **A11y MCP** — Runs accessibility/WCAG compliance checks against a web page or raw HTML,
  built on Axe-core (the same engine behind most browser a11y linters) with Puppeteer
  driving the page load. Lets an AI client answer "does this page pass WCAG AA?" and get
  back concrete violations with element references, instead of you running Axe manually
  and pasting the report in.
