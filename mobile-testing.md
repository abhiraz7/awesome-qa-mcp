# Mobile Testing MCP Servers

- **flutter-skill** — AI-driven E2E testing across 10 platforms (Flutter, React Native,
  iOS, Android, Web, Electron, Tauri, KMP, .NET MAUI) from natural-language instructions.
  Lets an AI client write and run a cross-platform test flow ("open the app, log in,
  verify the home screen") once and target multiple platforms instead of writing per-
  platform test code.
- [Oh My Android](https://github.com/ateymoori/oh-my-android) — Native macOS app (free, MIT) that controls the Android Emulator and real phones over adb; its built-in stdio MCP server (18 tools) lets AI clients such as Claude Code, Codex and Cursor take screenshots, inspect the layout in dp, toggle dark mode, font scale, locale/RTL and TalkBack, and mock GPS or network conditions.
