# awesome qa

a practical collection of qa skills, mcp servers and resources for people working across manual testing, test automation and ai/ml quality assurance.

the goal is simple: help your existing ai assistant become a more useful qa companion. the skills provide testing knowledge and workflows; the mcp directory points to tools that can connect an assistant to real systems when needed.

## start with qa skills

qa skills are reusable instructions for common testing work. they help an assistant reason about requirements, risks, test design, automation and ai system quality. they are useful on their own; mcp integrations are optional.

- [shared qa foundation](skills/foundation/README.md) — common principles for reliable testing.
- [manual qa](skills/manual-qa/README.md) — requirements, test design, exploration and defect reporting.
- [automation qa](skills/automation-qa/README.md) — automation design, framework quality and debugging.
- [ai/ml qa](skills/ai-ml-qa/README.md) — llm, rag, agent and model evaluation.

see the [skills guide](skills/README.md) for the current skills and how the collection is organized.
