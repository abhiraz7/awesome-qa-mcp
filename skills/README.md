# qa skills

qa skills are reusable instructions that help an ai assistant support real testing work. they focus on how to approach a task, what to consider, what evidence is needed and what a useful result looks like.

## how the skills are organized

- [foundation](foundation/README.md) — shared qa principles used across disciplines.
- [manual qa](manual-qa/README.md) — testing requirements, behaviour and user workflows.
- [automation qa](automation-qa/README.md) — reliable automated tests and maintainable frameworks.
- [ai/ml qa](ai-ml-qa/README.md) — evaluation of models, llm applications, rag and agents.

## using a skill

use a skill when its task matches the work in front of you. follow the assistant or editor's supported skill installation method. a skill should state its scope, inputs, workflow and expected output, and should not claim to have executed tests or inspected systems unless that actually happened.

skills should remain useful without an mcp connection. integrations can provide access to browsers, repositories, apis, databases and other systems, but they are not a requirement for using the guidance.

## current status

the collection is being built in stages. the foundation and one starting skill for each discipline are the first step; more specialized skills will be added as they are developed and evaluated.
