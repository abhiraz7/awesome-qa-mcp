# ai/ml qa

skills for validating machine learning models and applications that use llms, retrieval systems or ai agents.

- [llm testing](llm-testing/SKILL.md) — evaluate response quality, reliability, safety and regressions.
- [rag evaluation](rag-evaluation/SKILL.md) — evaluate retrieval, grounding and end-to-end answer quality.
- [ai agent testing](ai-agent-testing/SKILL.md) — test planning, tool use, permissions and recovery.
- [model evaluation](model-evaluation/SKILL.md) — assess model quality, robustness and regression.

planned areas include dataset quality, prompt injection, bias and safety, latency and cost evaluation.
