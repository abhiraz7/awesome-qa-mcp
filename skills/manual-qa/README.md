# manual qa

skills for testers who validate application behaviour directly and investigate issues through observation and evidence.

- [requirement analysis](requirement-analysis/SKILL.md) — clarify scope, acceptance criteria, ambiguity and test risks.
- [test design](test-design/SKILL.md) — create prioritized test conditions and cases.
- [exploratory testing](exploratory-testing/SKILL.md) — guide focused, evidence-led exploration.
- [bug reporting](bug-reporting/SKILL.md) — write clear and reproducible defect reports.
